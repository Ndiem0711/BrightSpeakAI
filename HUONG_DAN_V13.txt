BRIGHTSPEAKAI V13 — HUONG DAN SU DUNG

1. Giai nen toan bo thu muc BrightSpeakAI_V13. Khong chay trong file ZIP.
2. Mo GEMINI_KEY.txt, dan Gemini API key vao sau GEMINI_API_KEY= va luu.
3. Double-click START-BRIGHTSPEAK.bat. Can Python 3.11 hoac 3.12 va Internet lan dau.
4. Tai khoan local: student@demo.com / student123; teacher@demo.com / teacher123; admin@demo.com / admin123.
5. Vao Admin, bam Kiem tra AI. Neu API bao loi model/quyen/han muc, doc thong bao huong dan.

CHON GEMINI PRO
AI_MODELS.txt da dat GEMINI_MODEL=gemini-3.1-pro-preview.
Chi can sua ten model trong file nay roi dung STOP-BRIGHTSPEAK.bat va chay START lai.
GEMINI_LIVE_MODEL dung rieng cho Face-to-face, khong doi thanh Pro thuong.
Ten model duoc tham khao tu tai lieu Google ngay 16/11/2026. Quyen truy cap va han muc tuy tai khoan.
Pro van can Gemini API key hop le; viec doi model khong sua duoc loi key/han muc.
V13 chua tich hop OpenAI API. Tai khoan ChatGPT khong duoc dung thay cho API key trong ma nguon nay.
